Student Report Management System
Overview

The Student Report Management System is a console-based application developed in C. It is used to store, manage, and retrieve student information efficiently. The system supports role-based access and file storage to ensure secure and persistent data management.

Features

Role-based login system (Admin and User)

Add, view, update, and delete student records

Search student details by ID or name

File handling for permanent data storage

Simple and modular program structure

Project Structure

Main program files

Login and authentication modules

Student record management modules

Data storage text file

How It Works

The admin can manage all student records, while regular users can view limited information based on permissions. All data is stored in a text file, ensuring persistence even after the program is closed.

Requirements

C compiler (GCC or equivalent)

Standard C libraries
